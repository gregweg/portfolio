Full-Stack Coding Round Prep Notes

Today, I'm diving into preparation for a full-stack coding interview. The focus is on building a small healthcare-style member search interface from scratch, covering both frontend and backend aspects. This exercise helps solidify my understanding of React state management, API interactions, and best practices in web development.

Full-Stack Coding Round Prep

1. Frontend Portion

Goal

Build a small healthcare-style member search and details interface.

The UI should allow a user to:

  • Search for members by name or member ID
  • View a list of matching members
  • Select a member
  • View member details
  • See loading and error states

## 4. Frontend Talking Points

In a 45-minute interview, I would explain:

Data Fetching

The member search call should be debounced to avoid sending a request for every keystroke.

Error Handling

The UI should show a user-friendly error message instead of failing silently.

Accessibility

Important fields should use semantic HTML, such as tables for tabular data and role="alert" for errors.

Performance

For large datasets, filtering should happen on the server. The frontend should use pagination or infinite scrolling.

Security / Healthcare Context

The frontend should avoid exposing sensitive member data unnecessarily. It should only request and display the minimum information needed for the workflow.

## 5. Backend Design

Backend Goal

Expose endpoints for searching members and retrieving member details.

Example endpoints:

GET /api/members?query=greg
GET /api/members/:id

⸻

Backend Responsibilities

The backend should:

* Validate incoming query parameters
* Search members by name or member ID
* Return paginated results
* Avoid exposing unnecessary PHI/PII
* Handle not-found cases cleanly
* Keep controller logic thin
* Put business logic in a service layer

## 7. Sample Controller

typescript
import { Request, Response } from "express";
import { MemberService } from "../services/memberService";
export class MemberController {
constructor(private readonly memberService: MemberService) {}
async searchMembers(req: Request, res: Response) {
const query = String(req.query.query || "").trim();
if (query.length < 2) {
return res.status(400).json({
error: "Search query must be at least 2 characters",
});
}
const members = await this.memberService.searchMembers(query);
return res.json({
members,
});
}
async getMemberById(req: Request, res: Response) {
const { id } = req.params;
const member = await this.memberService.getMemberById(id);
if (!member) {
return res.status(404).json({
error: "Member not found",
});
}
return res.json({
member,
});
}
}

import { MemberRepository } from "../repositories/memberRepository";
export class MemberService {

## 10. Sample Routes

router.get("/members/:id", controller.getMemberById.bind(controller));
