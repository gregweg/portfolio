SIIP / PSTN Gateway

PTSN Gateway - (Public Switched Telephone Network) - traditional phone system. When someone calls a number it travles over PSTN.

SIP (Session Initiation Protocol) - protocol that bridges PSTN to VoIP/internet. A SIP/PSTN Gateway converts analog/digital phone signals into SIP packets your sytem can process. "Front Door" - twilio, vonage, signalwire

Real-time WebSockets - WebSockets hold a persistent bidirectional connection so data chunks can stream coninuously both ways wtih ~ 50-100 ms latency. In a voice pipeline, the aduio media stream RTP from SIP gets bridged to a WebSocket that your orchestration layer listens to. HTTP request/response would be too slow for things like gaming/voice

Whisper / Transcription - OpenAI's speech to text model (STT). Streaming-capable STT service that emits partial transcripts as the caller is still spoeaking, with a final transcript on silence/pause detection. The transcript then fires into the LLM orchestrator.

Voice Synthesis - Text-to-speech converts the LLM's response to audip. For low-latency, you stream the TTS - the LLM output tokens, you pipe them to a TTS service (ElevenLabs) which starts generating the audio before the full response is ready. This is called streaming TTS with sentence-level chunking -- you send sentence by sentence rather than waiting for the full LLM response. Target is under 500 ms time-to-first-audio.

Factory that hands the orchestrator a fully-loaded context object before first word is spoken.

Branching & Sentiment
Branching logic lives in the orchestrator, after each cnadidatre turn orchestrator evaluates the transcript and decides: continue current module, branch to deep-dive or advance to next phase. This can be rule-based (keyword triggers), LLM-evaluated (structured output from the same LLM), or a lightweight classifier
Sentiment/confidence scoring - typically a side-channel run in parallel not blocking the main loop. Lightweight modle scores each candidate response and writes to the session state. Orchestrator cna read those scores when making branching decisions but sentiment scoring doesn't sit in the critical path.
