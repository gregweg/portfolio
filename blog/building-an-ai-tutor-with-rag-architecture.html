How I’d architect a production AI Tutor

Given your background in distributed systems and the RAG pipeline you’ve been designing, I’d separate responsibilities like this:

  • Object storage (documents, PDFs, images, videos): raw source material.
  • Relational database (e.g., PostgreSQL): metadata, document hierarchy, users, lessons, learning objectives, permissions, and ingestion status.
  • Vector database (e.g., pgvector, Milvus, Qdrant, or Pinecone): semantic embeddings and approximate nearest-neighbor indexes.
  • Graph database (e.g., Neo4j, or graph tables in PostgreSQL if the graph is modest): concepts, prerequisites, curriculum structure, misconceptions, and links between concepts, chunks, questions, and examples.
